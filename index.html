Nothing is written, ever

The browser opens your save read-only to copy its bytes. It cannot alter, move or lock the file. Load it with the game closed so you're reading a finished save rather than one mid-write.

Reload after every jump

The numbers are a snapshot of wherever you were when that save was written. After a black hole or core jump, save, quit, and drop the file again.

How the distance is found

Each endpoint stores voxel coordinates; distance to the core is √(x²+y²+z²) × 400 light years. Destinations in a galaxy you've left are kept but greyed — the teleporter won't offer them.
